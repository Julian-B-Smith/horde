Shape

saw
structural waveform (stepped, ADR-173) · morphable width, bump amount and bump phase. polyBLEP on saw / square / pulse only — the idiom is the one the repo already trusts, reference/swarmsaw.html:626-633, not a second BLEP. bump is (sin θ + a·sin(3θ+φ)) / (1+a): a sine with a slightly phase-shifted third harmonic, which reads as a big bump followed by a slightly smaller one (measured lobe ratio 0.882 at the defaults). It needs no BLEP at all — two partials have nothing above 3·f0 to fold — which holds up to f0 = sr/6 (7350 Hz here); above that the third partial folds, and the harness pins that boundary rather than leaving it as prose. The two bump controls appear only when the waveform is bump.

Tone · level

one-pole TPT lowpass: the cutoff is a FREQUENCY and its coefficient is re-derived from the current sample rate whenever either changes. The naive 1−exp(−2π·fc/sr) form warps its response with the rate — measured −1.34 dB → −5.53 dB at Nyquist across 44.1…96 k, docs/audits/2026-09-18-saw-engine-audit.md §3.6. Not inherited here.

Sync

reset to start phase on a master wrap
LAB ONLY the master is a phase input the shell will supply (oscillator 1's phase). This page feeds it from a second internal saw so sync is auditionable before the routing exists — masterRatio is not a parameter and does not survive the port. Named limit: the reset discontinuity is not band-limited in v0 (spec draft §6).

Envelope SCAFFOLD

A short linear AR in seconds (ADR-009), here only so notes do not click. The shell replaces it with the voice envelope — it is not part of the module's identity, and the spec draft marks it provisional. The seed drives the noise shape's mulberry32 stream and is re-drawn at every note-on, so a bounce is reproducible (the SAW engine's unseeded ensemble stream, audit finding A3, is the trap being avoided).
