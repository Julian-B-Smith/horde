phase network (pre)

Three 2nd-order all-passes at centre/spread, centre, centre×spread. Flat magnitude; only the waveform shape changes — so the shaper's output changes while the input spectrum does not.

shaper — simplex blend

Weights are normalised to sum to one; the LUT is re-baked when they change. Poly fold: sin(½π·n·u(x)) with continuous order n and u(x) blending from linear (uniform folds, centre 0) to tanh (folds crowd toward the middle and flatten at the extremes, centre 1). Order 1 at centre 0 is the plain sine fold. Quantum walk drifts the weights stochastically.

memory (hysteresis)

Backlash: a play operator (dead-band that only moves when the input drags it) — the Preisach building block. Bias memory: the shaper's operating point follows a leaky average of its own output, so the transfer shifts depending on where the waveform has been. Drive memory: effective drive rides the difference between fast and slow envelopes — the shaper hardens (or relaxes) after loud passages.

interdependence

The fast envelope (of the pre-shaper signal) pushes phase-network centre and dispersion frequency in octaves. Every moving target (centres, dispersion, drive) is smoothed by one shared inertia so the chain lags and settles as one body.
