Module macro tiers

One FX slot with four fixed macro slots. Each slot is either global (one value, exposed to the DAW) or corner (a value per corner, reached only through intents). Morph position never changes what the DAW sees.

What the DAW sees

The exposed parameter list. It changes only when a slot's tier changes — never with morph. Tick a lane to fake DAW automation on it.

Things to try

  • Sweep morph. The Amount slot's label walks from Size to Depth; the DAW list is unmoved.
  • Flip Regen to global. It appears in the DAW list as FX1 Regen, its corner bindings grey out, and its value stops following the morph.
  • Automate morph from the DAW panel, then turn Space. Corner-level offsets still land coherently mid-morph because they ride the interpolated bindings.
  • Set both corners to the same module preset. The crossfade collapses to one instance; nothing else changes.
  • Motion is bound to a role that Diffuse doesn't implement. The knob still exists — it just does nothing on the A side.
