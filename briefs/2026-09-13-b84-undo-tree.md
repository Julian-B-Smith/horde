**Provenance.** HYPERSAW lead organ, 2026-09-13, for a scoped subagent with zero
conversation history. Motivating decision: ADR-160 (design ratified by the

## Acceptance criteria (verbatim from ROADMAP B84)

> (1) `src/undo_tree.h` — a pure, framework-free `UndoTree`: preallocated ring of `kUndoCap = 200` nodes `{parent, label, json, tick}`, no allocation after construction; a full ring evicts the OLDEST node and re-parents its children to its parent (a root's children become roots — a forest is legal); `current` node index; `push(label, json)` creates a child of `current` and moves `current` to it, and is a no-op when `json == current.json`; `undo()` moves to parent, `redo()` to the most recently CREATED child of current (the branch last taken), `restore(i)` moves `current` to any live node (navigation — no node is created; the next push forks from there). (2) The shell owns one tree per instance; nodes are created ONLY by MARKS — gesture END from the GUI (`hzGesture(id,false)`, label = the param's display name + osc), `applyStateJson` (preset load; label = "load"), `cornerApply`/`morphCapture` (labels "corner k"), the morphOn toggle, `state_load` (label "host load") — and NEVER by host parameter events or automation (B43(d) ruling: automated writes are not the player's, history records the player's states and automation keeps writing over the top as after any edit). (3) The snapshot is the existing `stateJson()`, taken on the MAIN THREAD at the first `hzFrame` (or next bind call) after the mark at which the param queue is drained (`qTail == qHead`); marks that arrive while the audio thread is stopped collapse into one node when it resumes. The audio thread touches nothing but is untouched: the mark is a main-thread act, the drain check is two atomic loads. (4) Restore = `applyStateJson(node.json)` and `current = node`; a restore is bit-identical: `stateJson()` after the queue drains equals `node.json` (the check asserts it through `tests/state_fixtures/`). (5) History is IN-MEMORY for 1.0 — never in the host chunk (`getStateInformation` unchanged, B43(b)); app-support persistence is a follow-up flag, not built. (6) GUI: a HISTORY page (`pg-HIST`, a page button beside the others) renders the tree as depth columns with the current node highlighted, any node one click to restore, Undo/Redo buttons, and Cmd/Ctrl+Z / Shift+Cmd/Ctrl+Z while the editor has focus; binds `hzUndoTree()` → `{cur, nodes:[{i,parent,label,tick}]}`, `hzUndoRestore(i)`, `hzUndo()`, `hzRedo()`. (7) `tools/undo_check.cpp`, standalone and unwired: ring eviction + re-parent, fork-on-restore, undo/redo path, dedup, the 200 cap, restore bit-identical through the fixture corpus, and the CONTROL: 500 host param events + 50 automation-shaped writes produce ZERO nodes.
