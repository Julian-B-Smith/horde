follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions
follow [semver](https://semver.org/). Each line is one merged change set and

evidence, the verify result and git hash). ADR numbers refer to
`DECISIONS.md`; B-rows refer to the open-work register in `ROADMAP.md`.

file was created (B101, 2026-09-10); re-type at the 0.1.0 cut if a line reads
wrong. Newest first.
