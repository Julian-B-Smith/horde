# b561-admission-test — the hosted-module admission test, standalone; run against Scape

- **Queue item:** B561 (ADR-295). Scape's brief `admission-readiness` (seq 1) asked horde to run the test; it had never been built. The human ruled by poll: "Now, standalone".
- **Why:** The contract (docs/proposals/rack-slot-contract.md §2.2 with §12) specified the admission test but no code ran it. This builds the module-only rows as a standalone check: one neutral harness with one adapter per module. Scape is the first module, built from its own tree and never written to.
- **What:** `tools/admission/` holds the harness. `module.h` is the neutral ABI. `harness.cpp` holds the rows. `plants.h` holds the must-fail controls: 25 wrappers, each injecting one fault through the ABI, so they are module-neutral. `scape_adapter.cpp` is the only Scape-specific file. `CMakeLists.txt` adds Scape's own `core/CMakeLists.txt` as a subdirectory, so Scape is built with its own flags. `tools/admission_check.py` is the driver. It locates the tree through `$HORDE_SCAPE_DIR` (default `~/Documents/Claude/synthetic-worlds/Scape`), runs the clean module and then every plant on its row, and judges a control fired when the plant run has a failure tag the clean run lacks. It runs A10 under RealtimeSanitizer, planted malloc first, using rtsan_check's compiler rule, imported. It writes `build-admission/<module>/admission-report.{md,json}`. It is wired into `./verify full` after the two rtsan checks.
- **Result against Scape** (clean export of origin/main `21cf07e`): A1–A6, A8–A10, A12, A15 and A17–A20 PASS, with every control fired. A21 is N/A (morphPosition not declared). **A11 FAILs** on `method[verb.era]`: Era's switch is a duck / swap / un-duck inside the module. Evidence: Scape spec/era.md §7 and reverb.cpp:740–769, where phase 1 fades the wet to 0, the incoming engine starts empty, and phase 2 fades it in. That is neither an equal-gain crossfade nor a declared `gate` nor a seeded jump, the only methods §12.1 and §12.2 admit. Scape's q027 self-assessment marks A11 "met". The REPORTED click reading for Era is up to 58.4 dB, against 3.1 dB for an ideal 20 ms equal-gain crossfade, on wet presets with the chord probe. The A10 timing (reported, not judged): the first 128-sample block after a reset with the morph keys moved took 0.68–0.77 ms, against a steady block's median of 0.054 ms.
- **Evidence consulted:** rack-slot-contract.md §1, §1.1, §2.1–2.2, §12; module-io-gain.md; fx-chain-morph-lab-r3.html `clickOf` (ported for the readings); tools/rtsan_check.py and h2_engine_rtsan_check.py; Scape fx_module.h, reverb.h, patch.h, fx_module.cpp, reverb.cpp, core/CMakeLists.txt (its plants, as models), core/tests/core_tests.cpp (the `ReverbTestAccess` seam), docs/admission/q027-self-assessment.md, spec/era.md; tools/tolerance_registry_check.py, build_flags_check.py, weakening_check.py, test_table_check.py.
- **Alternatives rejected:**
  - *Mutating copies of Scape's sources for the controls* (Scape's own plant method). Those plants are module-specific and live in the sibling's idiom. Wrappers through the ABI run against every adapter.
  - *Compiler flags in the Python driver.* build_flags_check pins direct compiles in `tools/*.py`, and a new pin needs the human's approval. The flags live in `tools/admission/CMakeLists.txt` instead. That file is outside build_flags_check's globs, which is reported to the lead as an open question, not hidden.
  - *Gating with invented thresholds.* Every gated comparison is exact, integer, or structural (a ramp within one of its own steps). A8's "collapse" is judged exact. The click readings are reported only.
  - *Pinning A11.* Adding a pin weakens a gate and is the human's call. PINNED is empty, so `./verify full` reads RED on a machine with a Scape tree until A11 is ruled or fixed.
- **Verify:** `nice -n 10 ./verify fast` exit 0 on the staged tree (see the PR for the tail). `python3 tools/admission_check.py` with HORDE_SCAPE_DIR set to the clean export: exit 1, RED on exactly A11 `method[verb.era]`, 77 s at load 5–8. Missing tree: WARNING + SKIPPED, exit 0. The export's file count equals `git ls-tree origin/main` (288), and no file in it is newer than its extraction.
- **Open questions:**

  - Whether build_flags_check's globs should cover `tools/**/CMakeLists.txt`.
  - Partial-collapse (A8) and morph step-size (A11) figures need a ratified threshold before they can gate.
  - A9's state half has no horde-side control. The only fault a wrapper could plant there is a fake one.
