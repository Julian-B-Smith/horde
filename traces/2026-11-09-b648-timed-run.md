# B648 timed run: the wavetable cost bench in thread CPU time (2026-11-09, quiet window)

**What changed.** Results only: this trace records the first timed run of `tools/quadrant_cost_bench.cpp` (merged #1461, source from origin/main 4ae1e97e), for ADR-388 #2 ("WT-BUDGET ruled after the timed run").

**How it ran.** A background job held the Mac awake (`caffeinate -i`), waited for the 2–6 am window (ADR-380 A1), and required Live closed, no `./verify` running and a 1-minute load under 3 before starting. The window opened at 02:16 (the machine had slept through part of the wait despite the idle-sleep hold); load stayed between 3.1 and 5.4 until 02:58, when it read 2.95 and the run started. Build `c++ -std=c++20 -O3`; `--checks` first (all PASS, incl. determinism with its must-differ controls), then `--timed --followup` and `--timed` (thread CPU time, best of 5, one PF-3 chord, 48 kHz unless noted). Load during the run: 2.80–2.95. **Caveat:** not an idle machine (load ≈ 3, other sessions open); thread CPU time is less load-sensitive than wall time, and best-of-5 favours the uncontended runs, but the figures may read slightly high.

**Calibration.** Against B648's instruction counts, the two cells measured both ways imply **20.5–20.6 × 10⁹ instructions per second** on this machine, about twice the 10 × 10⁹ the instruction-count estimates assumed. Every earlier "% of a core" figure derived from counts reads about 2× high.

| Linear with per-voice frame (WT-23 (a)) | 5.64 |
| Half-octave levels: Spectral log / Linear / Linear + per-voice frame | 6.84 / 6.59 / 5.63 |
| Crossfade scheme (ii), fused read | 5.19 |
| **Crossfade scheme (iii), one interpolated set per interval** | **4.80** |
| 8-point read at 4096 | 7.79 |
| Spec as written, morph static | 2.27 |
| First bench's design (2-point read, 2048 cap, fixed gain) | 1.95 |

**Against WT-BUDGET (4 % provisional per oscillator, ADR-385; 12 % for three, ADR-385 A1):** the specified design is 1.6× over (6.49 %); its cheapest measured variant, scheme (iii), is 1.2× over (4.80 %); static it is well under (2.27 %). Three oscillators at scheme (iii) moving: about 14.4 %. Against the older whole-oscillator target PF-1's 10.7 % per swarm oscillator, every cell fits. The bench is scalar and unoptimised (no SIMD, no precomputed interpolation coefficients); the reads are 54 % and the inverse FFTs 39 % of the moving cost (B648 follow-up), so the build's optimisation room is in those two.
