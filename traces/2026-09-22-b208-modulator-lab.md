**One shape law.** `shapeAt(points, t[, i0, v0])` sits inside a `/* ===== DSP ===== */ … /* ===== UI` span, so `tools/golden/extract_core.mjs` (design banner set) slices out `ModLabCore` with the laws as statics. The painters hold no law: the LFO curve comes from `core.lfoCycle(N)` (the B177 `hzGetLfoCycle` idiom), and the envelope and law-panel curves from `ModLabCore.envAt`/`envTauAt`. The page audits this on load and on every edit. It renders its own core offline at 8 kHz and compares the destination taps with the picture sample by sample. **The corrected laws** (each stated on the page, and each A/B-able with HEAR: PROPOSED | SHIPPED):
1. **Tempo division.** The stored value stays `lfoNBeats` (beats; id and range unchanged). The control is a named list of the 22 values inside the shipped 0.0625–8 range: straight 2/1…1/64, dotted 3/2…3/128 (1/1D…1/64D), triplet 2/1T…1/32T. The name is UI and the beats are the truth, following gui2's scale-picker ruling. No id moves and no patch migrates. An off-list value reads "≈ nearest ±x%". Worst adjacent ratio is 4:3, so the worst snap is **±15.47%**. Rejected: base × family as two controls. That is two automation lanes for one quantity, and it can name values outside the range.
2. **Start phase.** Phase is a live offset on the readout: `out = shape(frac(acc + φ))`. A retrigger rewinds `acc` to 0, so a struck note starts at φ, the shipped meaning kept. In sync, `acc` is derived from the transport (beats since bar 1 ÷ cycle beats). In free mode the output is identical to the shipped law for any patch whose φ has not moved since activation.
3. **Envelope time.** A stage's number is its arrival time. Curvature is a separate per-segment control, with `k = 2·ln100·c`, so **c = +0.5 is exactly the one-pole's shape** normalised to arrive. The migration that keeps an old patch's sound is τ × ln 100 = τ × 4.61 with c = +0.5. Rejected: relabelling the knobs as τ. That leaves the ×4.6 to the player, and a dragged breakpoint already is an arrival time.
4. **Other logic** (on the page, panel 4): the old mirror was not a mirror; a rate labelled in seconds was read as Hz; the old file made no sound; modulator-lab's envelope loop clicked; two time grammars; a false shipped comment about zero crossings; synced LFOs are not bar-locked; and the B208 row's "0.912 at 1·τ".

**Curve law changed** from `pow(x, e^(3c))` to the normalised exponential `(1−e^(−kx))/(1−e^(−k))`. The reason is that `f_{−k}(x) = 1 − f_k(1−x)`, so negating c is an exact mirror. The old pow mirror erred by up to **0.41** of a segment at c = 0.6 (0.11 at c = 0.2, 0.69 at c = 1). This was measured offline against `shape-lab-mod.html@3fd3a6b:119-122,238-239`.

## Open questions

- **The B208 row's "0.912 at 1·τ" is not the one-pole's value.** 1 − e⁻¹ = 0.632. "0.91" is what `lfoenv_check`'s first pass read at a probe instant it does not record (`tools/lfoenv_check.cpp:44-47`). The row is the lead's to correct. The lab uses 0.632.
- **Host-visible division:** should `lfoNBeats` itself become a stepped enum over the same 22 values (automation lands only on names), or stay continuous with the list as UI (proposed here, zero migration)? This is a human ruling. B171's finding (1) asks the same of the Delay's four beats params, which should move in the same change.
- **Transport lock needs host song position** (CLAP `clap_event_transport.song_pos_beats`). With no transport, or with the transport stopped, the sync phase needs a stated fallback (free accumulate from the last known position is the obvious one). Unruled.
- **Sample & hold** does not fit a breakpoint shape: a per-wrap draw is not a fixed cycle. The lab's STEPS is a seeded fixed table, not the shipped per-wrap S&H. Whether S&H becomes a sampler mode over the shape (modulator-lab's claim 2) is open.
- **The false zero-crossing comment** at `hypersaw_clap.cpp:2857` is a doc fix for the lead to queue. Out of scope here (`src/`).
- **Not built:** envelope LOOP (the LFO covers looping) and per-voice envelope scatter (modulator-lab had it; it is the gain envelope's feature, not this editor's).
