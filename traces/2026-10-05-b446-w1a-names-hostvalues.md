# b446-w1a-names-hostvalues — names cut at a character boundary and made valid UTF-8 before the GUI bridge; host note and tuning values checked at the event boundary

- **Queue item:** ROADMAP B446 (security overhaul), P1 Wave 1, item W1a. Lead brief of 2026-10-05 (horde lead session; the human: "let's proceed" after the P0 audit). Under B446's disclosure rule the P1 plan and its acceptance text are held privately, so the brief carried the acceptance criteria rather than quoting ROADMAP.
- **Why:** two input boundaries took values on trust. (1) Preset and corner names were cut by BYTE count (`substr(0, 60)`), which can split a multi-byte character, and names from session chunks and preset files were copied byte for byte; the webview library's JSON escaper requires well-formed UTF-8 (its own documented precondition, checked only by asserts absent from Release). (2) Host note keys and note-expression values reached the voice frequency unchecked, so an out-of-range key or tuning could make it infinite and the output non-finite.
- **What changed:**
  - `src/input_guards.h` (new, standard library only): `utf8Clean(text, maxBytes)` replaces each byte that does not begin a well-formed sequence with U+FFFD and cuts only before a whole character; `noteKeyInRange(key, wildcardOk)` (CLAP 0..127, -1 only where CLAP defines a wildcard); `kTuningSemisMax = 120` and `finiteClamp`; `zeroNonFinite` for the output.
  - `src/hypersaw_clap.cpp`: `setCornerName`, the `cornerNames` decoder and `setPresetName` cut through `utf8Clean(…, 60)` (every name ingest: typed, chunk `presetname=`, `morph=` and preset JSON all reach these three). `handleEvent`: a NOTE_ON outside 0..127 is dropped after the forensic trace records it; a NOTE_OFF/CHOKE outside 0..127 that is not -1 is dropped (-1 keeps its release-all meaning); a non-finite expression value is dropped, PRESSURE is clamped to 0..1 and TUNING to ±120 semitones (clap/events.h ranges). `process()`: non-finite output samples become 0, before the meters.
  - `src/gui/hypersaw_gui_common.h`: one `bridgeStr` helper (`createString(utf8Clean(s))`); all 25 string-returning bindings use it, including `hzPresetLoad`'s file contents.
  - `tools/bridge_utf8_check.cpp`, `tools/hostile_events_check.cpp`, their CMake targets, and both wired into `./verify full` after `notefuzz_check` (ADR-180 §1, additive; each declares `WIRED: ./verify full`).
- **Not changed, on purpose:** `libs/choc` (vendored, a human gate); `src/swarm_core.h` (its h2 lift is byte-checked by `h2_lift_check`, and the boundary is the shell's job, so the core needed no edit); velocity and transport tempo (outside this item's brief).
- **Evidence consulted:** the brief; the private P0 lane reports' W2-01 and L1-H2 sections; `libs/choc/choc/text/choc_UTF8.h` (`UTF8Pointer::operator++`, `popFirstChar`), `choc_JSON.h` (`writeWithEscapeCharacters`, `getEscapedQuotedString`); `libs/clap/include/clap/events.h` (key and expression ranges); `src/hypersaw_clap.cpp` name ingest sites, `handleEvent`, `process()`; `src/gui/hypersaw_gui_common.h` bindings; `tools/statefix_common.h` (reused harness); `tools/test_table_check.py` (wiring rule).
