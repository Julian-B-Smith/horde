# b628-bridge — GUI 3's bridge to the clean-room engine, in the test plug-in

- **Queue item:** B628 (the plan `docs/proposals/gui-on-engine.md`, sections 3, 4 and 7, RULED 2026-11-05), dispatched by the lead with the GUI session's later additions relayed (hash rule, meters, Voices read-back, fixture path).
- **Why:** the human asked to play GUI 3 on the real engine for sound testing. The bridge is planned as the B398 shell's first slice, so its seam is tested now rather than at cutover. This change builds the C++ side. A pure core (`bridge_core.h/.cpp`: messages in, snapshots out, the manifest hash, the saved state) sits behind the plug-in's existing lock-free edit queue (each page message is closed by an Ack entry, so `ack` is published in order). The window hosts the page in a choc WKWebView with the legacy shell's page-only policy. A shadow covers every engine row, while the 49 host parameters are kept. The saved state is version 2: the preset, Voices and the rows that differ from the preset ("current settings only").
- **Evidence consulted:** the plan (sections 1 to 8); ROADMAP B628; the engine API `engine2/tests/harness/horde_engine.h` at 1ad270a (GuiFrame, read_gui_snapshot, OutEvent, ParamInfo's lo/hi rule) and `core/api/engine.cpp` publish_gui; `src/gui/hypersaw_gui.mm`, `embedded_page_policy.h`, `hypersaw_gui_common.h` makeWebView; `tools/embed_file.py`; `docs/design/gui3/engine-stub.js` TRANSPORT and `device.js`; `params.json`; the GUI session's branch `gui-native-bridge` at 30abea48 (NativeTransport, `gen_gui3_controls.py --manifest-lines`, `gui3_browser_check.mjs`), read from a `git archive` export, nothing copied in; clap-wrapper v0.15.1's `make_clapfirst.cmake` and `base_sdks.cmake` (standalone).
- **Alternatives rejected:** waiting for the page's `hello` before sending params, presets and Voices (GUI 3's page sends no hello, and its schema refuses one; replaced by resending everything until a frame lands); 16-bit velocity read back raw (0.85 read 0.8500038; now rounded to four places); a clamp on the window scale (`scale > 1.0`, flagged by tolerance_registry_check; the override is now always the real scale); bending the replay fixture to preset index 0 so the GUI session's check passes (the check assumes index 0; reported instead); adjusting the hash format to match the page (forbidden by the lead; the 11 differing lines are reported); the standalone app (it needs RtAudio and RtMidi downloaded: two new dependencies, a human gate).
