## Three findings the harness produced about ITSELF, recorded because they are
## the interesting part

1. **The closed-form anchor caught the harness, not the core.** The tone
   magnitude row disagreed with `g/√(g²+tan²)` by **57.7 %** on the first run.
   The core was right; the harness had forgotten that `octave` defaults to −1, so
   it was measuring 493.88 Hz while the anchor computed 987.77 Hz. This is
   exactly why an oracle that needs no reference implementation is worth writing
   (LIBRARY L0031) — a parity-only check would have agreed with the mistake.
2. **A wrong assertion, corrected rather than weakened.** The first determinism
   row demanded that five notes of history leave the audio bit-identical. It
   failed — correctly: the envelope and filter state carry across a retrigger *by
   design*, which is what makes a legato retrigger click-free. The assertion was
   wrong, not the core. It is now the sharper property — **`allOff()` is a total
   reset; no stream survives it** — which is the SAW engine's A3 failure stated
   exactly (there, `tOff`/`tRng` survive every reset there is), with the
   "history without `allOff()` must differ" control beside it.
3. **A plant that does not fire (LIBRARY L0033).** The no-BLEP plant moves the
   sine and triangle rows by **0.0 dB** at every note, because neither shape goes
   through `subBlep`. Recorded as a coverage boundary in both the harness output
   and the spec draft (§10.1, limit L1) rather than retried until something
   fired: the triangle is a NAIVE shape and its −81.0 dB floor at MIDI 60 is the
   honest price.

## Alternatives rejected

- **An internal master oscillator in the core** for hard sync — rejected: the
  shell supplies oscillator 1's phase, so the master is an INPUT. It is an
  optional 4th argument to `render`; the lab's saw lives below the Audio-graph
  banner and does not port.
- **Naive `1 − exp(−2π·fc/sr)` one-pole** (what the SAW engine uses) — rejected
  on audit A7: correct time constant, rate-warped magnitude.
- **Exponential AR envelope** — rejected: a linear ramp reaches exactly 0 and 1
  in exactly the stated seconds at every rate, and leaves no denormal tail.
- **A second polyBLEP written for this module** — rejected on the reduce rule;
  the alias numbers are only comparable to the SAW engine's if the correction is
  literally the same one.
- **One alias threshold per waveform** — rejected: the floor moves 18 dB across
  the range, so a single limit is set by the top note and gives the bottom of the
  sub range no coverage at all (audit §3.1 asks for per-row floors).
