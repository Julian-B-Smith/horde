# 2026-11-07 — A headless AU bench for the reference synth (B638, ADR-380 decision 4)

**What changed.**
- **`tools/au-bench/au_bench.cpp`** (new): a command-line Audio Unit host that measures an installed instrument under PF-3's conditions, as the test author's CPU tool runs them. The chord is the k-th note on key 48 + 3·(k mod 8) at velocity 0.85, held from sample 0. The render is 0.25 s untimed, then 2 s timed. It takes the best of 5 interleaved repeats, a fresh instance per repeat. The calibration loop and the load guard run before every run, and the guard is never bypassed. It reports mean % of one core, the spread, the worst block as % of its deadline, and process CPU over all threads. It prints peak and RMS (silence or NaN fails the cell), the plug-in's latency and tail, and any polyphony or quality parameter. It takes `.aupreset` and Live `.adv` presets, and has must-fail controls (`--controls`). UNWIRED: it needs real AUs and a quiet machine.
- **`tools/au-bench/build.sh`** (new): builds `build-au-bench/au_bench` with the CPU tool's Release flags.
- **`tools/au-bench/README.md`** (new): how to run it, which preset formats it takes, what it measures, what differs from the CPU tool and why, and the controls.

**Why.** The human's request (2026-11-07): "Help me set up the Serum test and I'll pass you exports." This is ADR-380 decision 4, the human's reference reading of a heavy third-party patch on this Mac, in horde's unit.

**Controls** (`--controls`, Apple's DLSMusicDevice; all ok):
- C1: the guard's rule refuses planted readings.
- C2: the stand-in reads 0.34 to 0.53 % of a core across three runs.
- C3: the planted skip-the-render reads about 0.0002 % and is flagged silent.
- C4 to C6: a missing preset, a garbage one, an unsupported format and a wrong-component preset are each refused.
- C7: an `.adv` round-trip reads a moved parameter back, and an instance with no preset does not.
- C8 and C9: an `.adv` holding a VST3 device and an `.adv` with a corrupt buffer are each refused.

**First run on the reference synth: its DEFAULT patch, not the reference.** All 12 cells at 44.1 and 48 kHz, 128 and 512, and 8, 16 and 64 notes read about 2 to 2.6 % of one core. At 44.1 kHz and 128: 1.98 % for 8 notes, a worst block of 3.4 %, and process CPU equal to the wall share, so the work is single-threaded. The machine was noisy: calibration ranged 0.099 to 0.177 s, and the guard waited 8 times. Diagnostics: 0 notes is silent, 1 note reads −18.8 dB RMS and 8 notes −10.0 dB. Eight notes on MIDI channel 2 sound as on channel 1. So the flat 16- and 64-note cells are the default patch's polyphony cap, not the host. The human sets the voice count in the exported patch. The full report stayed outside the tree.
