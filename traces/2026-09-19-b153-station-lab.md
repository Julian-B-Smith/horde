# b153-station-lab — STATION layer 2: the three sanctioned lab edits, the §6 noise amendment, and a 20-row fidelity suite

- **Queue item:** B153 layer 2 (dispatch brief 2026-09-19; ruling ADR-177 §3).
- **Why:** The STATION audit (`docs/audits/2026-09-18-station-lab-audit.md`) found
  three defects in the protected prototype that are cheap to fix now and expensive
  after goldens exist, and the human sanctioned exactly those three edits plus the
  ±1→±0.7 spec amendment. Everything else in the audit is port-side and stays
  unfixed here. The suite exists because `./verify` has zero contact with STATION
  (audit §7): every number in the audit was uncovered, and `lab_load_check` only
  proves the file parses.

## What changed

### (a) `StationCore` — the class, sample-identical  (commit `0958e22`)
`reference/station.html` was the only prototype whose DSP `tools/golden/extract_core.mjs`
could not slice: no `DSP:`/`Audio graph` banners and no core class at all — `state`
and `render` were module globals. They are now fields and methods of `StationCore`,
inside the two banners; the UI is rewired to one `core` instance (10 call sites).
Two things had to become per-instance or two cores in one scope would share them:
the patch (a `mkState()` factory, not a literal) and the Wave-RAM RND stream.

**Proof it changed no sample.** The audit's §1.4 render — 3 s @48 kHz, all 12 matrix
cells at 8, three DRW ops at PURE 0.5 / QNT 16, looping envelopes, SHORT noise with
KEYTRK at rate 0.8, +24 st pitch env, two voices (MIDI 60 + 67), Wave RAM seeded
1024:

| | FNV-1a(L,R) | max abs diff |
|---|---|---|
| pre-wrap (`main`, re-measured today) | `bc9eea68afc8bfd9` | 0 |
| post-wrap | `bc9eea68afc8bfd9` | 0 |

The seed-1024 table is byte-identical to the audit's §1.1 record. `extract_core.mjs`
slices it with the **`reference`** banner pair (`/* ==== DSP:` … `/* ==== Audio graph`),
not the `design` pair the reverb fix added.

### (b) Per-voice LFSR seed  (commit `e6cc15d`)
Every voice seeded `lfsr: 0x7FFF`, so with KEYTRK off a chord's noise was one
waveform summed N times. `lfsrSeed(slot)` draws one mulberry32 value from
`state.seed ^ slot·2654435761` and forces it odd — 15-bit, never 0, reset on
note-on as before. Spec §6 already required "nonzero **per voice**".

| condition | 1 voice | 4 voices | ratio before | ratio after |
|---|---|---|---|---|
| KEYTRK off, same note | 6.858e-3 | 1.367e-2 | **3.999** | **1.994** |
| KEYTRK off, diff notes | 6.858e-3 | 1.367e-2 | **3.999** | **1.994** |
| KEYTRK on, diff notes | 6.858e-3 | 1.377e-2 | 2.016 | 2.008 |

Coherent = 4.000, independent = 2.000. LFSR periods unchanged and exactly spec §6
for all four distinct seeds: LONG 32767, SHORT 93, pre-period 0. Two fresh instances
still bit-identical (hash moved to `d867466ebf6ed6d5` — the noise stream changed
deliberately).

### (c) Nyquist limit in Hz, with the operator muted  (commit `b201d9f`)
`Math.min(opFreq(o,base)/SR, 0.45)` clamped the phase **increment**, so an operator
past the limit did not go silent — it went flat, by a sample-rate-dependent amount.
Now `f >= SR/2` → output exact 0 with the envelope still stepping (so the S9 freeze
is not re-introduced); otherwise `dt = f/SR`, unclamped.

Default patch, OP3 (ratio 14) alone, peak-bin pitch, 65536-pt Blackman-Harris:

| SR | MIDI 90 | MIDI 92 | MIDI 94 | MIDI 96 | MIDI 100 |
|---|---|---|---|---|---|
| 44.1 k before | −4.22 % | −14.67 % | −23.98 % | −32.27 % | −46.25 % |
| 44.1 k after | ok | silent | silent | silent | silent |
| 48 k before | ok | −7.13 % | −17.26 % | −26.29 % | −41.49 % |
| 48 k after | ok | ok | silent | silent | silent |
| 96 k before/after | ok | ok | ok | ok | ok (unchanged) |

Every reading is now the right pitch or exact silence (`peak|x| = 0.00e+0`); none is
a wrong pitch. Sweep over MIDI 24..108 × ratios {1, 7, 14} × {44.1, 48, 96} k:
**0 wrong-pitch readings**, worst deviation 0.67 Hz = one FFT bin.

### (d) SPEC-STATION §6 amended to ±0.7, §11 gains a divergence line  (commit `c5eae99`)
§6 said the LFSR output is ±1; `reference/station.html:289` has always rendered ±0.7
(3.098 dB, index ×1.429). ADR-003 makes the lab the reference, so the spec moved to
it, citing ADR-177 §3. §11 item 7 records that the seed **derivation** is not a parity
item — the rule, the periods, and the ~√N RMS ratio are. The lab's `0.7` is untouched.

### (e) The A/B render for the human (offered, not gated)
Two 4 s 48 kHz stereo WAVs in
`…/scratchpad/b153-lab/station-noise-pm-{0p7-as-shipped,1p0-old-spec}.wav`:
a noise-as-PM patch (NS → OP1, index **2.6** — the default patch's own cell value),
three notes at MIDI 36/43/48, rendered from the shipped lab and from an in-memory
planted core with the LFSR at ±1. The lab is never written.

| | ±0.7 (ships) | ±1.0 (old §6) | Δ |
|---|---|---|---|
| broadband RMS | 1.6401e-1 | 1.6542e-1 | +0.07 dB |
| third-octave, mean abs Δ over 28 bands | — | — | **2.00 dB** |
| worst band | 48.35 dB @63 Hz | 57.84 dB @63 Hz | **+9.49 dB** |

The worst band is the **carrier**, and it gets *louder* with more modulation. That is
not an anomaly: a bipolar-square modulator alternates the carrier between two fixed
phase offsets ±A, so the carrier term scales as cos(2πA). At index 2.6, A = 0.290
cycles at ±0.7 (cos = −0.248) and 0.414 at ±1.0 (cos = −0.857) — a 3.45× carrier,
+10.8 dB, against the +9.49 dB measured. Broadband level barely moves; what moves is
where the energy sits.

Index 4.0 was measured too and deliberately **not** used for the WAVs: there the ±1.0
side's peak deviation is 0.637 of a cycle, i.e. it wraps past a half turn, and the
comparison degenerates into a wrap artefact (mean |Δ| 11.40 dB, worst −14.44 dB @250 Hz)
rather than the level change the amendment is about.

### (f) `tools/labharness/station_check.mjs` — 20 rows, GREEN  (commit `c5eae99`)
The audit's §5 table as a runnable suite in the `reverb_check.mjs` idiom: extracts
`StationCore` live (never reimplements), plants pre-fix defects in memory for
must-fail controls, and verifies the planting mechanism itself with a bogus anchor
that must throw. `node tools/labharness/station_check.mjs` → **GREEN — 20 checks,
0 failed**, ~9 s.

**S8 is a correction to the audit, not a port of it.** Audit §4.4 offers the sideband
sign pattern as a one-sample-delay detector, asserting "a C++ port that reads the
current sample instead of `prev` produces a symmetric spectrum and **fails** the
asymmetry check". The must-fail control falsifies that:

- `PLANT_NO_DELAY` (the lab with the delay removed) reproduces the sign pattern to
  **0.000 dB** — identical to three decimals at every index;
- a synthetic exact PM signal built outside the lab reads the same +0.218 / −0.223
  (I = 2, |n| = 1) with the modulator delayed by one sample and with it not delayed.

Which is sound: one sample of delay on a sinusoidal modulator is a pure phase
rotation and |Jₙ| is invariant under it. The pattern is real and reproducible (lower
+0.15…+0.32 dB, upper −0.48…−0.22 dB, inside the audit's range) but it belongs to the
**analysis** — the lower sidebands fold through DC at fm = 7·fc — not to the delay.
Gating it would have been a detector confirming the expected answer for the wrong
reason. S8 now measures the delay directly in the time domain (carrier phase + the
modulator's output sampled every single-sample render, output inverted through the
monitor path): the shipped lab matches lag 1 at **4.75e-8** (float32 output
quantisation) and lag 0 at **1.20e-1**; the planted no-delay build reverses both
exactly. The audit's sideband numbers are still printed, as a report.

**Three other thresholds are this suite's own measurement**, each with the reason in
the file rather than a quietly widened tolerance:

- **S5 aliasing.** Agrees with the audit to **0.05 dB** over the 26 cells at MIDI ≥ 60
  above −60 dB — an independently written harness on the same lab, which is what
  justifies gating on a pin at all. Disagrees by up to **3.55 dB** on the MIDI 36
  column, because "worst NON-harmonic bin" depends on the harmonic-guard width when
  harmonics are 89 bins apart; and below −60 dB both probes read their own analysis
  floor (this one near −105 dB, the audit's near −94). Gated on the pin, cross-checked
  where meaningful, reported where not.
- **S10 noise flatness.** The audit's 0.6050 is unreachable over a fixed
  200 Hz–10 kHz band: the LFSR's zero-order-hold sinc null sits *at* the 8400 Hz clock,
  inside the band, reading 0.2272. Banding at half the clock gives **0.5799**. The
  control (rate 1.0, null outside the band) reads 0.6136 against the audit's 0.6779 —
  which is what identified the mechanism.
- **S16 parameter steps.** A single-shot |step| is a function of carrier phase — the
  audit says so itself ("the single 0.0039 reading for the ALG recall is luck").
  Measured as the median over 16 phases of |step| / the local natural inter-sample
  step, which is the audit's own 13.9× unit. The matrix row additionally needs OP2
  *sustaining*: in the shipped patch OP2's envelope is d 180 ms / s 0, so 100 ms after
  note-on a cell write moves almost nothing (1.8×) — the write is real, the modulator
  is not. Stated in the file, not tuned around.

**S20** had to bypass `noteOn()`'s 8-voice cap (`voices.shift()`) to measure 16 voices
at all; 16 `noteOn`s leave 8 sounding, so the "16-voice" reading was the 8-voice one.
The absolute cost is reported, never gated (machine-dependent); what is gated is that
the 8- and 16-voice scaling constants agree (0.64 / 0.64), which is what makes a
`measure_cpu`-style extrapolation on the ported core trustworthy.

S16–S19 deliberately **pin** known defects (no smoothing, no DC blocker, the op-OFF
envelope freeze, hard voice stealing) rather than demand their absence: all four are
build-side (audit §6.4, SPEC-STATION §4/§8), and a gate that fails from day one is a
gate nobody reads.

## Alternatives rejected
- **Seeding the LFSR from the note number** rather than the voice slot — rejected:
  two voices on the same pitch (a retrigger before release, unison layering) would be
  coherent again, which is exactly the case KEYTRK already failed to cover.
- **Raising the `dt` clamp to 0.5 instead of muting** — rejected: it removes the
  sample-rate dependence but still plays a wrong pitch, just a smaller one. The audit's
  own recommendation is to mute.
- **Keeping `TP`/`rndStream` module-level** in the class wrap — rejected: two cores in
  one scope would share the draw, so "two fresh instances" would stop being a
  determinism test.
- **Porting audit §5 row 8 as written** — rejected on evidence, see S8 above.
- **Editing `docs/design/station-page-lab.html`** — not done: its slice does not break
  (it slices its own `text/x-station-core` block, verified), and the brief scopes it to
  that condition only. See the open question.
- **Fixing the `0.1591549` literal or the 5 ms smoothing** — explicitly out of scope
  (the literal is the parity oracle's ground truth; the smoothing is the port's).
