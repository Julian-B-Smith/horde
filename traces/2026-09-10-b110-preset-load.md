# 2026-09-10 — B110: a full preset no longer truncates through the param queue

**What changed.** `kQCap` 256 → 1024. `applyStateJson` — the GUI preset LOAD
path — enqueues every key of a preset in one burst (~323 + osc-2 twins +
migrator writes) and `enqueueParam` drops on overflow, so at 256 the tail of
the table silently never landed (osc 2's enable among it; even ADR-103's own
migrator write). Found by the B100 stream's fixture generator, which refused
to pin it. Static array, 16 KB, RT-safe.

**Oracle.** `state_check` gains one assertion: set three late-table ids
(masterVol 100, osc-2 enable 1150, osc-2 pitch 1181), snapshot the FULL
state, scramble them, apply the snapshot, drain, read back. **Calibrated
must-fail:** with the cap at 256 the assertion reads RED; at 1024 GREEN.

**Verify.** `./verify full` exit 0.
