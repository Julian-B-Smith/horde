# b660-preview-weir-filter — Weir's SVF 12 as a test-only stereo filter after the engine in the engine-preview plug-in

- **Queue item:** B660 (the human, by poll: "A test-plug-in filter"; adding Weir as a build dependency of the test plug-in is approved by that choice).
- **Why:** to hear filters in Ableton now, before the engine has a filter slot. Test-only and outside the engine and its manifest; off by default, and off it touches nothing, so every preset, bit-identity test and recorded frame is unchanged.
- **Evidence consulted:** tools/engine-preview/{README.md, preview_plugin.cpp, bridge_core.{h,cpp}, build.sh, CMakeLists.txt, smoke.cpp, bridge_test.cpp}; Weir (read only, HEAD 078f143) include/weir/filter.h and svf.h (header-only), DECISIONS D-013/D-015; ADR-311 (horde prepares Weir with no ramp because PA-1 glides; here nothing does, so Weir's 5 ms ramp is on).
- **What changed:** `filter_core.h` (ids 0xA00010 to 0xA00015, laws, the `filter` state line), `post_filter.h` (Weir Svf12 in a stereo float wrapper, Weir ramp 5 ms), six host parameters after morph.x/morph.y, state version 5 written only when the filter differs from its defaults, `weir.pin` plus a configure-time check (HEAD equals the pin, `include/` unedited, else FATAL_ERROR; `HORDE_WEIR_DIR` defaults to `$HOME/...`, never an absolute path in a tracked file), a `preview-plant-nofilter` plant (the filter compiled out: the bit-identity reference and the no-op filter), README, tests.
- **Idle path:** on an idle engine (OU-4 skip) the filter still runs on zeros until Weir's own `tail()` is under 1e-7, so a resonant ring is not cut, and an idle plug-in stays cheap once it has rung out.
- **Alternatives rejected:** a Hz-valued cutoff parameter (CLAP has no log flag; Live's slider is linear in the value, so the host value is a log position and its text reads in Hz); a filter parameter in the engine manifest (out of scope: the engine is the clean room's); editing the page (the GUI session's).
- **Verify:** build.sh 6cd98b5 (build 4): bridge_test GREEN, smoke GREEN (every one of 99 presets bit-identical off vs the no-filter plant; LP 200 Hz high band x0.00001 vs x1.000 for the no-op plant; Mix 0 bit-identical to dry; state round trip), gui GREEN. `./verify fast`: see the commit's report (recorded in the hand-off).
- **Open questions:** the page shows none of the six (GUI session's); the committed gui3 replay fixtures are from 1ad270a, unchanged (frames lines unchanged by this work: the filter's parameters are not engine rows).
