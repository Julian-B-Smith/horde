The control is ULP: it nudges one sample of `T/mode 0 :: chord` and requires exactly one row NEWLY red against the keyed reference. ADR-221 already changes that row (it plays the default level), so the nudge cannot make it newly red: "0 row(s) newly red". Every way around this either hand-writes the reference, deletes the tracked reference so the tool takes its unkeyed path, or changes the control. Each is forbidden or needs the human, so the re-pin was not done.
