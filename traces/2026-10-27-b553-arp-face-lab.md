# b553-arp-face-lab — Arp's face in GUI 3's design system, as a lab

- **Queue item:** B553.
- **Why:** Arp's face and undo are horde's to build (Arp Q-H9, D-034). The lab draws all 47 settings of a dated snapshot of Arp's `spec/params.json` as a horde Module card, every control generated from the snapshot and bound by key, so the human can rule on the look before any GUI 3 code exists.
- **Evidence consulted:** the design system artifact's README, tokens.json, screens.md, accessibility.md, the READMEs and previews of ModuleCard, Knob, Switch, SteppedControl, TempoDivisions, EventLanes, GateLanes, Slider, ValueReadout, ScaleSelector, and `bundle.js` (Session, Knob, RateSync, ScalePicker, GateLanes); Arp `spec/params.json`, `spec/SPEC.md` (sections 4, 6, 8, 9, 14), `spec/bank/starter.json`, `DECISIONS.md` D-034 and D-035 (read-only, Arp HEAD `de4e2af`); `docs/design/mixer-lab.html`, `compact-lab.html` and `tools/gen_lab_index.py` for lab conventions. Files: `docs/design/arp-face-lab.html`, `docs/design/arp-face/` (tokens.css generated, bundle.css and bundle.js verbatim with a header line, params.snapshot.json, bank.snapshot.json, README.md).
- **Alternatives rejected:** editing `docs/design/index.html` by hand (it is generated from each tracked lab's own title, tagline and `lab-review` / `lab-part` meta, so the lab carries those instead); a hand-written key table (the layout names keys only for grouping, and the ledger proves all 47 landed, with a by-type fallback cluster so a new snapshot key can never be hidden); building the user-pattern editor (preset data, not in params.json, Q-H6); wiring `CornerChips` (its revert and lock write outside the undo stack).
- **Verify:** `nice -n 10 ./verify fast` exit 0 at base commit e2e7ebe plus the uncommitted B553 files (its first run was red on the B301 lab wheel check, three wheel listeners of mine; fixed by removing them, see the stray-gesture note in the lab); `lab_load_check.mjs` on the lab: GREEN. Driven in headless Chrome over DevTools at 980 and 600 px: no console errors, no horizontal scroll; a 12-move knob drag made one undo entry, a 5-tick alt+wheel burst one, a plain wheel none; a trigger made none; a click on the current pill made none; pill, stepper and toggle made one each; undo, redo and Cmd+Z worked only with keyboard mode on; no tab stop in the card or Advanced with it off; all 22 Arp rate divisions match RateSync's by name and all 18 scale names match the picker's.
- **Open questions:**
  - The snapshot has no input trigger key (Arp's triggers are outputs, SPEC 8), no lane settings (lanes are step data inside a pattern) and no frozen or exempt morph class (every key is continuous or discrete), so the trigger buttons are a labelled MOCK test of ADR-267 A1 and no key goes untinted.
  - RateSync has no morph pips (its Time slider is a plain slider), so `step_time_us` shows its editing corner's value instead.
  - The house scale picker always keeps the root lit; Arp allows `scale_deg0` off.
  - The labels of `scale_deg0..11` are not visible (the picker draws its own note names).
  - `bank.snapshot.json` was added to the vendored set because the `pattern` setting's values live in the bank.
  - The navigator `index.html` was not regenerated (it lists tracked labs only); the lab carries the meta for the next regeneration.
