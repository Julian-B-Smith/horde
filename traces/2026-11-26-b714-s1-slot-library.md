# b714-s1-slot-library — one generic module slot hosts the test plug-in's FX from data alone

- **Queue item:** B714 stage 1 (ROADMAP.md B714; ADR-410 r4, ADR-411, ADR-412 as the lead's brief states them; ADR-412 is not yet in DECISIONS.md on this branch).
- **Why:** acceptance (1), (6) and (9), and (5) in part: a module is hosted from its pin, manifest, state-budget row (and horde's interim law/mod overlay) through one library, `tools/rack`, with no per-module branch left in `preview_plugin.cpp` or `bridge_core.*`; old chunks migrate or are refused loudly; off is a true bypass; the module-neutral tests are generated from the slot table and gated in `./verify full`.

  - `tools/rack/test/` (new, its own commit): the do-nothing test module by data alone.
  - `tools/engine-preview/`: `preview_plugin.cpp`, `bridge_core.*`, `bridge_ext.h`, `smoke.cpp`, `bridge_test.cpp`, `CMakeLists.txt`, `build.sh`, `README.md` onto the rack; `host_ids.lock.json`, `foundations.pin`, `fixtures/migration-goldens.json` new; `weir.pin` to 92ff8af; `filter_core.h`, `reverb_core.h`, `post_filter.h`, `post_reverb.h`, `test_rows.h` deleted (ADR-412 r1).
