## What the swarm found (the real yield)

1. **Every loaded preset was partially applied** — the JSON path enqueued ~323
   keys through a 256-slot queue that drops on overflow. Found by B100's fixture
   generator, which *refused to pin it*. Fixed (#543).
2. **`finishRebuild` sorted on the audio thread with a heap-allocating
   `std::stable_sort`** on libstdc++ — invisible on macOS/MSVC by library
   accident. Found by B101's first Linux sanitizer run. Fixed (#540).
3. **MAIN's macro knobs remapped to phantom ids whenever OSC 2 was edited**
   (no `data-fixed`). Found by B105 deriving its picker list. Fixed (#542).
4. **The saw-shape section aliases at high notes and the reference shares it**
   — parity certifies it. Found by B103's measurement. Filed B109 for goldens v2.
5. **`rtsafety_probe` is blind to nothrow-new** (B112) and **`gui_reach`'s
   patch-scope pin misses 161–177** (B113) — two gates that certified real
   defects. Gate edits, human-gated.
6. **`lab_load_check` never swept `reference/`**; two prototypes fail its stub
   (B108). Pre-existing.
7. **The macOS post-merge CI job had been red since the 08-27 rename.** Fixed
   in #532; provable only after merge.
8. **A private sibling's real name reached main** inside a trace's quoted grep
   pattern (#531) — the leak gate fires only where the untracked names file
   exists, i.e. the lead's checkout. Hotfix #539.

## Lessons the lead recorded (REFLECTIONS, library candidates)

- An external audit's binary framing is not evidence about a standing ruling;
  check the ledger first (the SPECTRA lapse).
- The leak gate is lead-only: run `./verify` on merged main after every agent
  merge — that is what caught #531.
- Gate every scripted commit on the verify exit code; twice a chain committed
  past red (a rebase conflict, the leak gate) and once a PR body claimed green
  before it was.
- Parallel agents share the session scratchpad; two streams overwrote each
  other's files. Unique scratch names per agent.
- Concurrent probe runs sharing one output artifact make verdicts
  unattributable (B105's finding, distinct from L0032).
- A brief's pointer was wrong (mulberry32 is not in `swarmsaw.html`); the
  agent found the right source and flagged it rather than guessing.
