HORDE Map Mode

Map mode prototype. The modulators are running live, so mapped knobs move. Turn on MAP (or tap M; hold M for momentary), pick a source, then click or drag knobs on any page. With MAP off, hold ⌥ Option and drag a knob to change mod depth, or ⌥-click to switch which modulator you're adjusting.
