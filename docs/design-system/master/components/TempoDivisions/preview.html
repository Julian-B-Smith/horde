Rate and sync
Divisions
One control for a rate: FREE in Hz, or SYNC to a tempo division. The stepper walks the list slow to fast; the table is the whole list at once. Both write the same stored beats. A value off the list (a loaded patch) keeps its value and reads as the nearest name, ± the difference. Nothing lights for it.
