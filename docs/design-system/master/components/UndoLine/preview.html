Modulators (the thin rows' x removes)

Press x on LFO 1 (two routes), then Undo: the modulator and both routes come back in one step. S&H 1 has one route; Velocity is an engine source, so it leaves the list but the engine keeps it (the line says so, and + brings it back). The line keeps its place when empty so nothing moves. In the shell the host also puts the removal on its own history, so the shell's undo does the same.
