MOD-MAPPING RULESETS
A rule is a pattern: which sources may drive which destinations, over what range, and how its source is shaped (a pitch envelope is only a pitch envelope when the envelope is fast). ARCH on MOD MAPPINGS (or on GLOBAL) clears the unlocked slots and draws routes: a count in the range below, each slot a rule by weight, then a source, a LIVE destination and an amount. A source that one rule has shaped is not reshaped by another in the same draw. PARAMS on MOD MAPPINGS re-draws only the amounts, inside each route's rule range.
