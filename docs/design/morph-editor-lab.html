What a row can be

Every member behaves one of three ways, and the grid marks which on every row — without it a player watches one value slide while its neighbour jumps and concludes the instrument is broken. In QUANTUM a continuous row also flips corner-by-corner, but the morph glide () carries the value across the flip, so it still arrives by sliding; a structural row takes the winner's value outright (morphApplyTarget), so it never passes through a value no corner chose.
