NOTE
The B263 patch model, pared down to one oscillator, two 2-slot racks, an 8-slot modulator bank and an 8-route list. Four corners hold every value; the patch holds two shared lists that only grow (routes, modulators); each side of the pad holds one rack lineup; the bank is split into fixed zones, one per part; a lock holds a value still under morph. Load presets and watch where they land: an oscillator preset writes one corner or all four, a rack preset swaps a side, a new route appears at depth 0 in the corners that did not ask for it, and a full list refuses the whole load and says why. It sounds — POWER plays one voice through both racks, X is an equal-power crossfade — and the cost readout does not move with the puck, because both racks always run. Drag a value cell vertically to edit that corner; ⊘ locks a row.

What the model still leaves open — with recommendations

  1. A rack swap and that side's corner values. The lab discards the old modules' values — they belonged to modules that no longer exist — and writes the preset's values into both corners of the side, along with its modulators and routes. Recommend: keep that, and give the swap one level of undo. It is the only load that removes anything, so it is the only one that needs a way back. Do not carry values across a swap even when module types match: a preset should sound like itself.
  2. How big each zone is. The lab uses 3 source · 2 rack A · 2 rack B · 1 global. Recommend: make the sizes format constants, like the route cap, never user-resizable: resizing renumbers slots and silently rewires routes. Size the source zone from the preset library — the largest number of modulator KINDS any shipping oscillator preset uses, plus one. Merge-by-kind means presets in four corners share slots, so the source zone does not need to be four times a preset.
  3. Whether a loaded modulator merges or claims a new slot. The lab merges by (kind, ordinal): Glass's LFO and Razor's LFO are one slot whose rate morphs from 5.5 Hz to 0.25 Hz across the pad. Recommend: merge. It keeps the lists bounded, and it is where the discovery is: morphing between two presets morphs their shared modulators rather than cross-fading two static ones.
  4. How a list ever shrinks. Lists only grow, so a patch fills up. The lab's PRUNE removes routes at depth 0 in every corner, then modulators no route uses. Recommend: make PRUNE an explicit action, never automatic. Automatic cleanup would delete a route at the moment you set it to 0 in the last corner, just before you dial it up in another.
  5. A one-rack patch. The lab passes the dry signal on the empty side, so X fades from wet to dry. Recommend: keep it. It adds no rule, because an empty side is just a rack with no modules. To vary one rack across all four corners, load the same rack preset into both sides; that honestly costs two racks. Letting one rack span both sides would add a third lineup state and a special case to every side-load.
  6. Locks and preset loads. The lab skips a locked value on load and says so ("kept 1 locked value"). Recommend: skip. The main use of a lock is browsing presets while pitch or level stays put. A load that wrote through a lock would change the corners underneath it, and unlocking would then jump, which ADR-109's write-into-all-four rule exists to prevent.
  7. Whether modulation moves a locked value. The lab locks the MORPH (ADR-109: exempt leaves the morph field), and routes still modulate the value. Recommend: keep. A lock that also froze modulation would be a second feature, and depth 0 already provides it.
  8. Partial loads. A load that does not fit is refused whole; nothing is written. Recommend: keep it atomic. Loading the values without the routes would give you a preset that does not sound like itself. That silent partial load is the kind of refusal that loses data, and the only kind that would earn --alarm.
  9. A modulator's rate in a corner whose preset does not use it. A new slot's rate starts at the preset's rate in every corner. After that, a load that does not use the slot leaves its rate there alone, so mid-pad the rate blends toward a value no preset chose. The depth is 0 in that corner, so it is quiet at the corner itself. Recommend: accept it for now, because it is part of the discovery. Revisit if players hear the blend as a bug.
  10. Routes between parts. In the lab a part's modulators only reach its own values, so a rack swap can drop routes without touching the source. Recommend: keep it, and make the GLOBAL zone the only one that crosses parts. A global route into a rack is then the one route a swap can orphan, and the swap message has to name it.
