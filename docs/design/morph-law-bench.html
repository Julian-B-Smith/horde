The shared substrate — what both models agree on

Every send cell route.from.to holds four authored values, one per corner (A SPLIT · B CRUSH · C DUB · D WASH). A value of 0 means not connected — disconnection is a gain, not a separate fact, so no cable list exists and no cell can be "invalid". The matrix is upper-triangular (a module sends only rightward in rank), so every possible assignment is a DAG by construction — QM-3 forbids even writing a validity checker, and our routing core enforces the same rule read-side. Zero-send rows normal to master (dashed). None of this is in dispute. The dispute is only: as the XY moves, how does a cell get its value?

Trade-offs — what each law buys and pays

BLEND (continuous)ARGMAX (QM-0 discrete)
Mid-field sound A weighted hybrid that no corner authored — smooth, wash-prone; a 50/50 point is half-gain everything A mosaic of authored values — each cell is always something someone designed; the combination may still be unauthored (QM-3 test 6 engineers for worst-hybrid survivability)
Discrete params (type, char, sync) Unhandled — needs a hidden second law; the clicks live there anyway Uniform — the whole point of one selection law
Continuous sweep of a cutoff via XY Native Impossible — values quantize to corners; smoothness comes only from glide + commit timing
Determinism Pure function of XY — trivially recallable Function of XY + seed + noise table + commit clock — recallable (QM-0 serializes all of it) but the contract is bigger
Performance dimensions One: position Position + temperature + coupling + reshuffle + commit class — a generative instrument, not a crossfader
Click surface Gains continuous by construction; discrete flips (the hidden law) still click; continuously-varying delay TIME pitch-smears Every change is a step, all masked by one glide mechanism; QM-3 test 5 pins it at −60 dB
UI attribution A cell is a mixture — ownership is fractional, census is fuzzy Every cell has one owning corner — the demo's colored census is honest and legible
Normalling threshold (row < 0.01 → master) XY can HOVER at the threshold — the master normal can chatter under a slow drag; wants hysteresis Crossed only at commits — chatter bounded by commit rate
Not a dial between them: temperature→0 gives nearest-corner (a step function of the field), NOT blend. Blend is outside the argmax family at every T. The expected value over many reshuffles approaches the blend — but any single realization is a mosaic. These are two instruments, not two settings.

The decision actually being made

Option A — pure BLEND. The morph pad is a precision crossfader. You lose temperature, coupling, reshuffle, and the mosaic character; you gain smooth interpolation of every gain and every continuous param. You still need a discrete law for type/char/sync, so "pure" is already hybrid.
Option B — pure ARGMAX (QM-0 as specced). The morph pad is a probability field quantized to musical time. You lose XY-sweepable cutoffs; you gain one uniform law, per-corner attribution, and the generative performance surface. This is what the demo and QM-3 assume.
Option C — split by the line QM-3 already draws. QM-3 §6.3 splits commit timing into param class vs routing class. Splitting the LAW on the same line — routing + discrete flip by argmax, continuous params blend — gives sweepable cutoffs AND mosaic topologies. Cost: two laws for real, a fuzzier census (blended params belong to no corner), and coupling groups that span both laws.

My read, stated so it can be distrusted: B is the more novel instrument and C is the more playable synth; A is the industry default and the least interesting. The QM documents are coherent and complete around B — adopting C means asking the QM side to carve an exception whose census and coupling semantics they have not designed. If B is chosen, ADR-088's rationale text must be AMENDED (the dense table survives; its justification changes from "morph interpolates coefficients" to "unauthored = zero + flips glide through zero"), because a rationale that no longer matches the law is how the next agent re-derives the wrong thing.
