horde aesthetics lab

Bench for auditioning control aesthetics — human request 2026-08-17: "could we start a lab for testing alternative aesthetics? I want to play around with a lighter color scheme, styles like skeuomorphism, rotary dials instead of sliders, etc." It settles nothing about DSP and touches no plugin parameter — this file is not connected to the running instrument and never pretends to be (no bridge, no CLAP param ids, no audio at all: it is silent on purpose, since wiring in sound would imply a live parameter path that does not exist here). What it settles is how a control should look and feel to operate. Six panels below render the SAME six controls — three continuous, one bipolar, one stepped enum, one toggle — crossed three themes (dark / light / skeuomorphic) × two widget styles (linear / rotary). All six renderings of a given control share one value: drag any of them and every other rendering updates too, so the comparison is honestly the same parameter six times, never six that quietly drifted apart. Drag a dial vertically or tab to it and use the arrow keys — see the code comment by bindDialDrag for why vertical, not angular.
1.00×
Plugin control real estate is fixed by the host, not by us — a style that reads fine at lab scale can become a smear of pixels at the size a DAW actually gives a synth. This slider scales every rendering's geometry at once (canvas AND CSS both read the same density value — see dialGeom() and the --density custom property), so "does this survive small" is a drag, not a guess.
A GLASS
Corner colour flipping (human, 2026-08-17: "some things need to flip together, other things can be discrete, and that often comes down to a matter of taste, and everything that flips needs to have its corner colour"). Drag morph from A to D and watch each control's label rule and dial ring. Every param carries a flip mode, shown as its glyph: quantum jumps colour on the corner boundary, gradual blends along the way, semi blends in discrete hops at the refresh rate, and frozen/system-wide never changes and shows no colour at all — absence reads as "belongs to nobody", never as a grey corner. The assignments below are a seed, not a design: which params share a corner and which flip how is exactly the taste decision this control exists to make visible. Vocabulary is the standing mod-lab convention (A GLASS · B GRIT · C HOLLOW · D BLOOM), so this auditions the presentation of corners the instrument already has.
running
Modulation on a parameter — a live signal riding the value. Two marks, deliberately distinct: a translucent depth band showing the reachable range, and a small dot at where the sound is right now. The pointer or thumb stays the user's value; the dot is the modulated one. Confusing the two is the classic mod-viz failure, so this bench keeps them apart in both widget styles. Detune, volume and pan carry modulation; the rest sit at zero on purpose, because a mod visual that cannot look absent is as bad as one that cannot look present. The signal is a plain sine — this auditions how modulation looks, not any modulator.
