Morph field — the composition that had never been built

Load the preset, hold a chord, then drag the field. Each corner owns one routing and blends with its weight, so the corners are four different instruments: A slow filter sweep · B detune motion · C chorus swell · D phaser motion. ENV→Kboost is system-wide — it keeps its onset bite everywhere, which is the point of that scope. Measured across the field: rms 0.077…0.106, peak 0.251…0.494 (corner C quietest, D loudest). + self-drive adds LFOB→morphX so the field sweeps itself — watch flips/s and pull hysteresis to 0 to hear the chatter it prevents. The K1→K cell is morph-owned: it carries four depths, one per corner (A +0.8 locks · B −0.8 splays · C 0 silent · D +0.4 pulls gently), shown as the four tinted numbers under the cell with the live one lit. Crossing a boundary swaps which one applies — the flip changes the routing's character, not whether it exists. Typing in a morph-owned cell edits the current owner's value, so move the field to author each corner.
flips/s: 0
Drag the field, or route a source to morphX / morphY in the matrix and let a modulator drive it. This is the collision made audible: a morph-owned routing flips the instant the field crosses a boundary, so an LFO on morphX crossing one repeatedly produces a stutter — watch flips/s climb. Hysteresis is the fix that was missing: a challenger must beat the incumbent by a margin, so a hair-width crossing no longer flips. At 0 you get the raw chatter; the flip counter is the evidence either way.

Consolidation A/B (onset lock vs env→K)

A sets onset 0.8 / dissolve 1.2 s (the dedicated params). B zeroes them and routes ENV→Kboost at 0.64 per-note (each note its own env instance). Findings so far: #1 the generic K destination can't reach onset's strength (km caps at 4; onset 0.8 injects 5.12) → coupling-domain destination required. #2 a GLOBAL env re-surges every sounding note on each new key — per-note instances are required for the poly feel (uncheck per-note to hear the defect). Judge on CHORDS and staggered lines.

Kuro chorus (ADR-053 demo dest)

own swarm
Tap i is modulated by rotor voice i — so K is the chorus character knob: +1 taps move as one (unison vibrato) · 0 free ensemble drift · −1 even lattice, maximally decorrelated (the "past free" state a unipolar macro cannot reach). Sweep K with mix up. Feedback → flanger territory.

Kuro phaser (rotor → notches)

own swarm
Stage j is steered by rotor voice j mod 4, so K sets how the notches move relative to each other: +1 sweeps them as one (classic phaser) · 0 independent churn · −1 evenly distributed lattice. Stereo comes from the swarm — the right channel reads a rotated voice assignment. Mix 0.5 = deepest notches (dry+wet cancellation).
