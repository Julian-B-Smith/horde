Evolution surface for CANTO, the FOF/pulsar formant engine — the protected reference reference/formant-pulsar-fof.html stays untouched, because an edit there is a spec change. Two things live here. Formant detune width voices each formant with several slightly detuned grains panned apart: the supersaw move applied to formants, so the beating lands inside the vowel while the pitch stays solid (the sub is deliberately never detuned — it is the one thing that must stay planted). Grain de-click fixes a real, register-dependent click: a FOF grain ends at the -60 dB point OR a hard cap, whichever comes first, and register narrows bandwidth as pitch falls, which lengthens the decay — so low notes hit the cap and the grain vanishes at a finite amplitude, all five formants stepping on the same period boundary and summing. Measured -62 dB at 220 Hz, -46 at 55, -32 at 27.5. Set grain fade to 0 to hear the reference exactly; the readout names which regime you are in. Grains run as recursions (rotate a unit vector for the carrier, one multiply for the decay) rather than a sin() and an exp() per sample — verified equal to the closed form to 1e-14. Masking is seeded, unlike the reference. Polyphony was built and reverted (2026-08-23): the audio cut out past six voices while every in-page instrument reported healthy, and both were blind by construction — the analyser taps the graph rather than the device, and ctx.currentTime is the device clock, which advances straight through an underrun. The voice machinery is pinned to one, so restoring it is one line if the engine earns it.
