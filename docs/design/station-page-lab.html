PM Matrix

Rows FEED columns; a cell is a PM index (0–8) and 0 IS "not connected", so connecting and disconnecting is one continuous motion. Drag a cell vertically or scroll it; double-click restores the boot patch. The diagonal is self-FB. Every tap reads the previous sample (§2), which is what makes any cycle stable. NS has no column: noise receives no PM, so the destination does not exist — absent, not disabled (gui2:473).
