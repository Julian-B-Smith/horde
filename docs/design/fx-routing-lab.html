FX routing lab — tidy wires and a send matrix, one wire model

GB21, ADR-410. Your ask: wires kept tidy, rational and separated, a routing matrix that shows each send's percentage, and real values. Every wire here holds a level at each corner; the pad blends them as Heard. Ruled (GUI-75): W1 and L1. Drag from one box onto another to make a wire (it lands at 100 %); drag a percentage up or down in either view, and to 0 to remove it; double-click a matrix cell for the default, 100 %. Both views read and write one model.

Every level here is MOCK, built to the shape the plug-in's bridge will publish (B715); in the plug-in the same views read the bridge. Inputs per source are open (B528) and marked MOCK. Return wires are dashed and carry z⁻¹: feedback is built, one sample late, and a Settings toggle can prevent it (ADR-411); "Prevent feedback" in the bar stands in for that toggle.
