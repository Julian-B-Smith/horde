3 · Critical gaps, in order

B427–B433 each have an owner row. None is dispatched, and none is yet in H2-PLAN's order. Each is placed at the point where it gets more expensive to do later.

  1. Trademark knockout on every user-visible name, now, before the names freeze (B433).
  2. clap-wrapper v0.16+, and a parameter fallback for every modulation destination (B429 (4), (6)), before the shell.
  3. Frozen identities: the lockfile diff, the AU parameter order, the VST3 class ID (B428), at the shell skeleton.
  4. Output guard, FTZ/DAZ, nothrow-new probe (B430), at the skeleton.
  5. clap-validator in CI on macOS and Windows (B427), from the first artefact.
  6. Sustain pedal, init patch, mono/legato, MTS-ESP (B431), with the bend-laws port.
  7. Tails, SLEEP, latency (B429 (1)–(3)), when the rack hosts a tailed module.
  8. Concurrency, steals, fuzzing, cross-platform goldens (B430), once state exists.
  9. GUI on real platforms (B432), with GUI 3.
  10. Notarise, sign, notices, licence (B433, B412), at the release candidate.
  11. pluginval, real hosts, auval (B427), at the release candidate.

The pink line is the 34 % slice (B439). Heavy patches are over under every caveat; the size of the gap (1.1×–3.1×) is not settled. One oscillator was timed; B327's voice has two.

The plan:

  1. Measure clean. Commit auhost --engine, run unloaded at 44.1 kHz, time both oscillators, and cover all 83 presets.
  2. Profile the blade render, the 80–89 % of the cost that is not swarm. Then do the output-neutral kernel work: B378 F1, F7, F9, and whatever the profile finds. Parity digests stay unchanged.
  3. Rule the edge correction (B383), then test os 1 against os 2 on each heavy preset, one ledgered divergence at a time.
  4. A polyphony and quality policy (B323, B375). Factory presets fit the slice, or declare a deterministic voice or member count. A user may exceed it; a preset never imposes it.
  5. Measure ×1.5 once on real min-spec hardware.

CPU stays Layer-E, never a verify gate (ADR-187 §8). It gates the bar, not the freeze.
