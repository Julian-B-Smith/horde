Q2 · Where the 3 × 3 PM matrix lives

Rows are the oscillator being modulated, columns the modulator. The diagonal is each oscillator's own feedback (WT-61). Every cell is a corner value like any other control, so it blends across the pad. Drag a cell, or a wire, up or down to set its depth.
