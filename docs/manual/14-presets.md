# Presets and the factory library

Purpose: explain how sounds are saved, found and shared. A global preset holds four corners and
the global attributes, and saving one also files each corner on its own for mixing. The chapter
covers the browser and file manager, the init patch, what a preset stores (including its quality
setting), module presets inside a global preset, the factory library, copy and paste, bringing
sounds over from horde legacy, and what horde promises about old presets after 1.0.
