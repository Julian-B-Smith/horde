# Parameter reference

Purpose: list every parameter horde exposes: its name as the DAW shows it, its page and panel,
range, default, unit, morph class and whether it can be modulated. This chapter is GENERATED, not
written by hand: a tool will produce its tables from the engine manifests and the committed
parameter lockfile, so it can never disagree with the plugin. No table here is to be typed in.
Until the manifests and the lockfile exist, the chapter is an outline of the tables to generate.
