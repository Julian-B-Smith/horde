3

The new engine rebuilds its whole parameter context thousands of times a second

Leadsmall · bit-identical

An id-to-index table at prepare; build the context only when an action is due; share one per tick. No golden moves. This path survives the blades' retirement.

engine.cpp:207  voices_.run_actions(context(), …)  // every segment
engine.cpp:185,189  context() again per grid and control tick
manifest.cpp:370  param_index = std::lower_bound(…)   // per read

The builder's own note-start profile, blades off: about 18 % of process() for the first line and 28 % for the ticks. Not measured by me.

Leadsmall

5

Humana workflow change

Carry the row, ledger entry and trace as the last commit of the PR they record, or batch them into one records PR per session. Either removes about six merges a day.

300 PRs in 19 days, all merged by one person. Records PRs: median 40 lines in 3 files, median 56 minutes waiting, a 5-minute CI run each.
